# Path Planning and Tracking for Off-road Machine with Electro-Hydraulic Actuation

## Overview

This repository contains my bachelor thesis project at Tampere University.

Autonomous navigation is increasingly important for off-road machinery operating in unstructured environments such as construction sites and mines. Two components determine whether such a machine can reach its target safely: path planning and trajectory tracking. The aim of my thesis was to select and validate a suitable planning and tracking framework for a machine equipped with Electro-Hydrostatic Actuator (EHA) steering, while treating the actuator's physical constraints as an explicit part of the evaluation rather than ignoring them.
